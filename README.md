# LabVideoTransription

Проект помогает получить содержательный конспект встречи по видео, аудио или готовой транскрипции: выделить основные идеи, понятия, правила, ключевые вопросы и практику применения, если она обсуждалась.

Конспект сохраняет рассуждения, которые раскрывают понятия и связывают их между собой, а также значимые примеры, метафоры и описания телесных ощущений. Краткость получается благодаря отбору и организации материала; сокращение объёма само по себе не является целью.

## Как устроена работа

Материал проходит три волны:

1. **Подготовленная транскрипция.** Сверка распознаваний и исправление ошибок с сохранением авторства, ID и таймкодов. Существенные сомнения проверяет человек по записи.
2. **Ход развития мысли.** Как ставились вопросы, на что обращали внимание участники и как формулировались идеи.
3. **Итоговый конспект.** Связное объяснение содержания простым языком, проверяемое по источнику.

ИИ помогает сверять и организовывать материал. Неясные места отмечаются, оговорки и разногласия сохраняются; недостающие шаги практики не додумываются.

Основные результаты сохраняются в `output/<название встречи>/`:

- `03 — Полная транскрипция.md` — утверждённый источник;
- `04 — Ход развития мысли.md` — развитие обсуждения;
- `<название встречи> - конспект.md` — итоговый документ.

## Что используется

| Инструмент | Назначение |
|---|---|
| Zoom | Один из источников транскрипции с таймкодами, если доступен. |
| AssemblyAI | Облачное распознавание записи, определение языка и разделение по говорящим. |
| Python | Сохранение JSON, создание диалога и адресное извлечение реплик. |
| FFmpeg / FFprobe | Предварительное извлечение звуковой дорожки из видео без повторного сжатия. |
| Markdown | Читаемые транскрипции, вопросы для проверки и итоговые документы. |
| ИИ-агент и локальные навыки | Корректура и подготовка конспекта по правилам проекта. |

Скрипты готовят транскрипцию и удобный для чтения диалог. Сверка смысла и составление конспекта выполняются с участием ИИ-агента и человека; один запуск Python не создаёт готовый конспект.

Если уже есть аудиофайл, он отправляется на распознавание напрямую. Если есть только видео, сначала `extract_audio.py` извлекает аудио, затем на распознавание отправляется полученный аудиофайл. Это уменьшает объём загрузки; стоимость распознавания той же длительности не меняется. Команды и выбор дорожки описаны в [AGENTS.md](AGENTS.md), установка FFmpeg — в [INSTALL.md](INSTALL.md).

## Структура проекта

```text
LabVideoTransription/
├── README.md                       # знакомство с проектом
├── INSTALL.md                      # установка среды и настройка сервисов
├── AGENTS.md                       # рабочий процесс и правила проекта
├── requirements.txt                # зависимости Python
├── .env.example                    # пример переменной API-ключа
├── .gitignore                      # исключения для локальных данных
├── main.py                         # запись → JSON и Markdown-диалог
├── extract_audio.py                # видео → исходная аудиодорожка через FFmpeg
├── create_dialogue.py              # существующий JSON → диалог с ID и временем
├── read_dialogue.py                # выбранные реплики из текущего Markdown
├── .agents/skills/
│   ├── transcript-proofread/        # навык корректуры
│   └── conspect/                    # навык хода мысли и итогового конспекта
├── scripts/                        # вспомогательная обработка выгрузок чата
├── tests/                          # локальные проверки без обращения к сервису
├── input/                          # локальные исходные материалы
└── output/                         # результаты по встречам и архивы редакций
```

Папки `input/` и `output/` создаются по мере работы и исключены из Git вместе с `.env`, локальным окружением и временными файлами. В репозиторий входят код, инструкции и безопасный пример настройки ключа.

## Документация

- [INSTALL.md](INSTALL.md) — Linux/macOS, Python, библиотеки, API-ключ, Zoom и устранение ошибок установки.
- [AGENTS.md](AGENTS.md) — от источников до проверенного конспекта: команды, сверка, diff, уточнения, результаты и критерии готовности.
- [transcript-proofread](.agents/skills/transcript-proofread/SKILL.md) — подробные правила корректуры.
- [conspect](.agents/skills/conspect/SKILL.md) — подробные требования к ходу развития мысли и итоговому конспекту.
